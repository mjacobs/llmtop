# llmtop v0.1.0

llmtop is a terminal UI for watching NVIDIA GPUs and the LLM servers that use
them. It runs on Linux and can show local and remote GPUs in the same window.

## Install

Build from source with Go 1.26 or later and a C compiler. GPU monitoring needs
the NVIDIA driver at runtime. Run `llmtop --demo` to try the UI without a GPU.

```sh
go install github.com/mjacobs/llmtop/cmd/llmtop@v0.1.0
```

To install from a checkout, check out `v0.1.0` and run `make install`. This
release ships source.

## What you can monitor

- GPU utilization, memory, temperature, and power, with history charts and
  a breakdown of LLM serving versus other GPU activity.
- llama.cpp and vLLM throughput, KV-cache usage, and slots. Strata reports
  throughput and slots. NInfer reports model, context length, and concurrency.
- Local servers discovered by process scan and servers declared in the config.
- Remote hosts through `llmtop agent`, with an optional bearer token and a
  systemd user service.

This first release freezes the agent snapshot format and includes replay tests
using recorded llama.cpp and vLLM responses.

## Maintainer release procedure

Use the approved release SHA and the expected remote `main` SHA recorded in
the release issue. Run from a clean checkout of that exact commit. Follow the
[wire-format checklist](README.md) before preparing a candidate. Any change to
the candidate requires fresh verification and approval.

After publication approval, check the target and push the approved SHA. The push
starts CI for both supported Go versions. Wait for that run before tagging.

```bash
set -euo pipefail
repo=mjacobs/llmtop
tag=v0.1.0
sha='<approved-release-sha>'
remote_base='<expected-remote-main-sha>'

test "$(git rev-parse HEAD)" = "$sha"
test -z "$(git status --porcelain)"
git cat-file -e "$sha:internal/model/testdata/wire/$tag.json"
remote_main=$(git ls-remote --exit-code origin refs/heads/main)
test "${remote_main%%[[:space:]]*}" = "$remote_base"
remote_tag=$(git ls-remote --tags origin "refs/tags/$tag")
test -z "$remote_tag"

git push origin "$sha:refs/heads/main"
gh run list --repo "$repo" --workflow CI --event push --branch main \
  --commit "$sha" --json databaseId,headSha,status,conclusion,url
```

Once the run appears, use its ID below. Keep the variables from the previous
block in the same shell. The signed tag is checked by its peeled commit SHA.

```bash
run_id='<ci-run-id>'
gh run watch "$run_id" --repo "$repo" --exit-status
ci=$(gh run view "$run_id" --repo "$repo" \
  --json headSha,headBranch,event,workflowName,conclusion,url)
jq -e --arg sha "$sha" '
  .headSha == $sha and .headBranch == "main" and .event == "push" and
  .workflowName == "CI" and .conclusion == "success"
' <<<"$ci" >/dev/null
ci_url=$(jq -r .url <<<"$ci")

git tag -s "$tag" "$sha" -m "llmtop $tag"
git push origin "refs/tags/$tag"
remote_target=$(git ls-remote --exit-code --tags origin "refs/tags/$tag^{}")
test "${remote_target%%[[:space:]]*}" = "$sha"

notes=$(mktemp)
trap 'rm -f "$notes"' EXIT
git show "$sha:docs/releases/$tag.md" |
  sed '/^## Maintainer release procedure$/,$d' >"$notes"
printf '\nRelease commit: `%s`. [CI run](%s).\n' "$sha" "$ci_url" >>"$notes"
gh release create "$tag" --repo "$repo" --verify-tag \
  --title "llmtop $tag" --notes-file "$notes"

gh release view "$tag" --repo "$repo" --json tagName,isDraft,body,url |
  jq -er --arg tag "$tag" --rawfile notes "$notes" '
    select(.tagName == $tag and (.isDraft | not) and
      (.body | rtrimstr("\n")) == ($notes | rtrimstr("\n"))) | .url
  '
```
